One haiku about debugging, written in the 5-7-5 shape by a small Node program that writes it to `/output/entry.txt`:

> The last log line glows
> where the server died at three
> it was my own print

Run it with `node main.ts`. It validates the 5-7-5 syllable shape and the 200-character limit before writing.
